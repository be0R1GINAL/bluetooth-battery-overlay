# Portable / Портативная версия

Распакуйте архив в папку, доступную для записи, и дважды щёлкните `Start Bluetooth Battery Overlay Portable.cmd`. Установка и права администратора не нужны. Настройки сохраняются в `settings.json` рядом с программой. Чтобы удалить портативную копию, закройте оверлей через настройки и удалите распакованную папку.

Extract the ZIP into a writable folder and double-click `Start Bluetooth Battery Overlay Portable.cmd`. No installation or administrator rights are needed. Settings are stored in `settings.json` beside the app. To remove the portable copy, exit the overlay from Settings and delete the extracted folder.

The portable and installed copies can run at the same time; each keeps its own settings.
